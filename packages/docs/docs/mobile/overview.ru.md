# Обзор мобильного приложения

Мобильное приложение Anote AI разработано с использованием [Expo](https://expo.dev) и React Native.

## Особенности

- Поддержка нативных iOS и Android
- Светлый/темный режим (следует системным предпочтениям)
- Интерфейс чата с потоковыми ответами
- История сеансов с выдвижной боковой панелью
- Безопасное хранение JWT через `expo-secure-store`

## Запуск локально

```bash
cd packages/mobile
npm install
npx expo start
```

Сканируйте QR-код с помощью приложения Expo Go или запустите в симуляторе.

## Конфигурация

Установите URL API через переменную окружения:

```bash
EXPO_PUBLIC_API_URL=https://api.anote.ai npx expo start
```
