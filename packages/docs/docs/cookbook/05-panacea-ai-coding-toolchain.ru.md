# Panacea AI Инструмент Кодирования

Этот рецепт объясняет, как опыт кодирования с использованием ИИ от Panacea реализуется через CLI, SDK и VS Code.

## Что вы узнаете

- Разные точки входа для кодирования с использованием ИИ в Panacea
- Как CLI, SDK и расширение VS Code связаны с общим бэкендом
- Ключевые возможности продукта для частной помощи с кодом
- Где искать детали реализации в репозитории

## Почему это важно

Panacea разработана как единый продукт с несколькими интерфейсами:

- **CLI**, который управляет `anote chat`, поиском кода и обзором репозитория
- **Расширение VS Code** для помощи с ИИ в редакторе
- **SDK** для встраивания Panacea в другие приложения

Эти интерфейсы используют общий бэкенд и слой рассуждений на основе агентов, что делает продукт последовательным на настольных, веб- и кодовых рабочих процессах.

## Ключевые файлы Panacea

| Файл | Почему это важно |
|---|---|
| `Panacea/packages/cli` | Реализация CLI на TypeScript для рабочих процессов разработчиков |
| `Panacea/packages/vscode` | Расширение VS Code и интеграция чата |
| `Panacea/packages/sdk` | SDK на TypeScript для программного доступа |
| `Panacea/packages/backend` | Общая служба бэкенда, обеспечивающая все взаимодействия UI и CLI |

## Как это работает

- Действие пользователя по кодированию начинается в CLI, SDK или расширении VS Code.
- Запрос отправляется в API бэкенда Panacea.
- Бэкенд использует оркестрацию агентов и поставщиков моделей для получения ответов, учитывающих код.
- Ответ возвращается в том же интерфейсе с предложениями по коду, объяснениями или исправлениями.

## Полезные функции продукта

- **CLI**: `anote chat`, поиск репозитория, обзор кода, генерация кода и помощь на основе встраиваний.
- **VS Code**: встроенный чат, предварительный просмотр различий, действия с кодом и потоковые ответы.
- **SDK**: обертка клиента для API Panacea, позволяющая создавать пользовательские интеграции.

## Запустите локально

Из корня рабочего пространства (`anote/panacea`):

```bash
cd Panacea
cp packages/backend/.env.example packages/backend/.env
docker compose up --build
```

Это запускает общие службы бэкенда и фронтенда.

В другом терминале запустите пакет CLI:

```bash
cd Panacea/packages/cli
npm install
npm run dev
```

Теперь вы можете использовать CLI локально или собрать его с помощью `npm run build`.

Для разработки в VS Code откройте `Panacea/packages/vscode` в VS Code и запустите расширение с отладчиком.
