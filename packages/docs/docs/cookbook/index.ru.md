# Обзор кулинарной книги

Кулинарная книга Panacea — это набор руководств по реализации, показывающих, как работают функции платформы Panacea на практике — загрузка документов и RAG, оркестрация многопользовательских агентов, выставление счетов, сервер инструментов MCP и многое другое. Каждое руководство указывает на реальные файлы бэкенда, участвующие в процессе, и объясняет, как запустить эту часть системы локально.

Источник: [anote-ai/Cookbook](https://github.com/anote-ai/Cookbook).

## Запуск рецепта локально

Большинство рецептов работают с полным стеком Panacea:

```bash
cp packages/backend/.env.example packages/backend/.env
docker compose up --build
```

Смотрите [Начало работы](../getting-started/installation.md) для полного набора, а также страницу каждого рецепта для его конкретных шагов запуска.
