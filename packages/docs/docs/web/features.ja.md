# ウェブアプリの機能

## チャットインターフェース

メインのチャットビューはChatGPTのデザインを反映しています：セッション履歴のある折りたたみ可能な左サイドバーと、中央に配置されたメッセージスレッド、下部に入力バーがあります。

## ライト / ダークモード

右上のボタンで切り替えます。設定は`localStorage`に保存されます。

- **ライト**: 白/薄灰色の背景、黒いテキスト
- **ダーク**: `#212121`/`#2F2F2F`の背景、白いテキスト

## ストリーミング

入力は`POST /api/chat/stream`リクエストを送信し、SSEレスポンスを読み取ります。ストップボタンでストリーミングを中止できます。

## セッション

各会話はサーバー側に保存されるセッションです。セッションはサイドバーにリストされ、ページの読み込みを跨いで持続します。
