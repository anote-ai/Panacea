# 웹 앱 기능

## 채팅 인터페이스

주요 채팅 뷰는 ChatGPT의 디자인을 반영합니다: 세션 기록이 있는 접이식 왼쪽 사이드바와 중앙에 위치한 메시지 스레드, 하단 입력 바가 있습니다.

## 라이트 / 다크 모드

우측 상단의 버튼으로 전환합니다. 선호도는 `localStorage`에 저장됩니다.

- **라이트**: 흰색/연회색 배경, 검은색 텍스트
- **다크**: `#212121`/`#2F2F2F` 배경, 흰색 텍스트

## 스트리밍

입력은 `POST /api/chat/stream` 요청을 보내고 SSE 응답을 읽습니다. 중지 버튼은 스트리밍 중단합니다.

## 세션

각 대화는 서버 측에 저장된 세션입니다. 세션은 사이드바에 나열되며 페이지 로드 간에 지속됩니다.
