# 网络应用程序功能

## 聊天界面

主要聊天视图与 ChatGPT 的设计相似：一个可折叠的左侧边栏显示会话历史，以及一个居中的消息线程和底部输入栏。

## 明亮/黑暗模式

通过右上角的按钮切换。偏好设置保存在 `localStorage` 中。

- **明亮**：白色/浅灰色背景，黑色文本
- **黑暗**：`#212121`/`#2F2F2F` 背景，白色文本

## 流式传输

输入发送 `POST /api/chat/stream` 请求并读取 SSE 响应。停止按钮可以中止流式传输。

## 会话

每个对话都是存储在服务器端的会话。会话在侧边栏中列出，并在页面加载之间保持。
