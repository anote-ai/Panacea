# Функции веб-приложения

## Интерфейс чата

Основной вид чата отражает дизайн ChatGPT: сворачиваемая левая боковая панель с историей сеансов и центральная ветка сообщений с нижней строкой ввода.

## Светлый / Темный режим

Переключение с помощью кнопки в правом верхнем углу. Предпочтение сохраняется в `localStorage`.

- **Светлый**: белые/светло-серые фоны, черный текст
- **Темный**: `#212121`/`#2F2F2F` фоны, белый текст

## Потоковая передача

Ввод отправляет запрос `POST /api/chat/stream` и читает ответ SSE. Кнопка остановки прерывает поток.

## Сессии

Каждый разговор является сеансом, хранящимся на стороне сервера. Сессии перечислены в боковой панели и сохраняются между загрузками страниц.
