# Обзор веб-приложения

Веб-приложение Anote AI представляет собой интерфейс чата в стиле ChatGPT, который подключается к бэкенду Anote.

## Особенности

- Светлый и темный режим (автоопределение системных предпочтений)
- Потоковые ответы через SSE
- История сеансов чата в сворачиваемой боковой панели
- Выбор модели (Claude, GPT-4o и др.)
- Загрузка документов и вопросы-ответы
- Адаптивный дизайн

## Запуск локально

```bash
cd packages/web
npm install
npm run dev
```

Приложение работает по адресу `http://localhost:3000` и проксирует API-запросы на `http://localhost:5000`.
