# 網頁應用程式功能

## 聊天介面

主要聊天視圖反映了 ChatGPT 的設計：一個可折疊的左側邊欄，顯示會話歷史，並且中間有一個消息線程和底部輸入欄。

## 明亮 / 黑暗模式

使用右上角的按鈕切換。偏好設置會保存在 `localStorage` 中。

- **明亮模式**：白色/淺灰色背景，黑色文字
- **黑暗模式**：`#212121`/`#2F2F2F` 背景，白色文字

## 串流

輸入會發送一個 `POST /api/chat/stream` 請求並讀取 SSE 回應。一個停止按鈕可以中止串流。

## 工作階段

每個對話都是一個存儲在伺服器端的工作階段。工作階段在側邊欄中列出，並在頁面加載之間持久存在。
