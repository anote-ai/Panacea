# Обзор настольного приложения

Настольное приложение Anote AI — это приватный AI-ассистент, работающий в оффлайн-режиме и созданный с использованием Electron.

## Ключевые свойства

- **Приватность**: все данные остаются на вашем устройстве
- **Оффлайн-режим**: работает с локальными моделями Ollama
- **Кроссплатформенность**: Windows, macOS, Linux
- **Встроенный бэкенд**: бэкенд на Python Flask упакован как отдельный исполняемый файл

## Архитектура

```
Electron shell
  └─ React frontend (Vite + Tailwind)
  └─ Встроенный Python бэкенд (исполняемый файл PyInstaller)
       └─ Flask API на порту 5099
       └─ SQLite база данных (локальная)
       └─ ChromaDB векторное хранилище (локальное)
```
