# デスクトップアプリの概要

Anote AIデスクトップアプリは、Electronで構築されたプライベートでオフライン対応のAIアシスタントです。

## 主要な特性

- **プライベート**: すべてのデータはあなたのマシンに保存されます
- **オフライン対応**: ローカルのOllamaモデルで動作します
- **クロスプラットフォーム**: Windows、macOS、Linux
- **バンドルされたバックエンド**: Python Flaskバックエンドはスタンドアロン実行可能ファイルとしてパッケージされています

## アーキテクチャ

```
Electronシェル
  └─ Reactフロントエンド (Vite + Tailwind)
  └─ バンドルされたPythonバックエンド (PyInstaller実行可能ファイル)
       └─ ポート5099のFlask API
       └─ SQLiteデータベース (ローカル)
       └─ ChromaDBベクターストア (ローカル)
```
