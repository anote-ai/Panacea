# Python SDK

Клиент на Python доступен через пакет `anoteai` (часть репозитория Anote-Product).

## Установка

```bash
pip install anoteai
```

## Использование

```python
from anoteai import Anote

client = Anote(api_key="sk-ai-...")

# Существующие публичные методы аутентифицируются с помощью Authorization: Bearer sk-ai-...
result = client.classify(document_id="doc_123", labels=["contract", "invoice"])
answer = client.answer(document_id="doc_123", question="Какова сумма платежа?")
```

Создайте API-ключи в Настройки -> API Ключи. Открытый ключ отображается один раз; после этого отображается только префикс ключа.

Стоимость кредитов:

| Операция | Кредиты |
| --- | ---: |
| Загрузка документа | 1 за файл или URL |
| Сообщение в чате / Вопрос-Ответ | 1 за запрос |
| Завершение чата, совместимое с OpenAI | 1 за запрос |

Обрабатывайте ошибки API по коду состояния:

| Статус | Значение |
| --- | --- |
| 401 | Отсутствует или недействительный API-ключ |
| 402 | Недостаточно кредитов |
| 429 | Превышен лимит запросов для ключа |

Смотрите [репозиторий Anote-Product](https://github.com/anote-ai/anote-product) для полной документации SDK.
