# VS Code Erweiterungsfunktionen

## Chat-Seitenleiste

Öffnen Sie das Anote AI-Chat-Panel aus der Aktivitätsleiste. Stellen Sie Fragen zu Ihrem Code, erhalten Sie Codevorschläge und überprüfen Sie Unterschiede.

## Inline-Diff-Überprüfung

Wenn der Agent Dateiänderungen vorschlägt, wird automatisch eine Diff-Ansicht geöffnet. Akzeptieren oder lehnen Sie jede Änderung einzeln ab.

## Streaming-Antworten

Antworten werden tokenweise in Echtzeit gestreamt. Eine Stopptaste ermöglicht es Ihnen, während des Streams abzubrechen.

## Sichtbarkeit der Toolnutzung

Sehen Sie genau, welche Dateien der Agent während jeder Antwort liest, schreibt oder ausführt.
