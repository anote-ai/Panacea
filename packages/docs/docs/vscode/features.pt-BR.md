# Recursos da Extensão VS Code

## Barra Lateral de Chat

Abra o painel de chat do Anote AI a partir da barra de atividades. Faça perguntas sobre seu código, obtenha sugestões de código e revise as diferenças.

## Revisão de Diferenças Inline

Quando o agente propõe alterações em arquivos, uma visualização de diferenças é aberta automaticamente. Aceite ou rejeite cada alteração individualmente.

## Respostas em Streaming

As respostas são transmitidas token por token em tempo real. Um botão de parar permite que você cancele durante a transmissão.

## Visibilidade do Uso de Ferramentas

Veja exatamente quais arquivos o agente lê, grava ou executa durante cada resposta.
