# Extensão do VS Code

A extensão do Anote para VS Code fornece assistência de IA inline diretamente no seu editor.

## Recursos

- **Barra lateral de chat** — painel de chat de IA persistente com histórico de sessão
- **Ações CodeLens** — Explicar / Corrigir / Testes / Refatorar acima de cada função
- **Injeção de contexto** — adicionar código ou arquivos selecionados ao chat
- **Busca semântica** — pesquise seu código a partir da paleta de comandos
- **Revisão de diff inline** — aceite ou rejeite edições de IA arquivo por arquivo
- **Anexo de arquivos** — anexe imagens, PDFs e arquivos de texto ao chat

## Instalação

Pesquise por **"Anote"** no marketplace de Extensões do VS Code.

Ou via CLI:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Configuração Rápida

1. Abra o VS Code
2. Execute `Anote: Set Up` a partir da paleta de comandos (`Ctrl+Shift+P`)
3. Escolha seu provedor (Anthropic direto ou via servidor Anote)
4. Insira sua chave de API
5. Abra o painel de chat a partir da Barra de Atividades
