# VS Code 拡張機能

Anote VS Code 拡張機能は、エディタ内で直接インラインの AI アシスタンスを提供します。

## 機能

- **チャットサイドバー** — セッション履歴を持つ永続的な AI チャットパネル
- **CodeLens アクション** — 各関数の上に説明 / 修正 / テスト / リファクタリング
- **コンテキストインジェクション** — 選択したコードやファイルをチャットに追加
- **セマンティック検索** — コマンドパレットからコードベースを検索
- **インライン差分レビュー** — AI の編集をファイルごとに受け入れるか拒否する
- **ファイル添付** — 画像、PDF、テキストファイルをチャットに添付

## インストール

VS Code 拡張機能マーケットプレイスで **"Anote"** を検索します。

または CLI を使用して：

```bash
code --install-extension anote-ai.anote-ai-coding
```

## クイックセットアップ

1. VS Code を開く
2. コマンドパレット (`Ctrl+Shift+P`) から `Anote: Set Up` を実行
3. プロバイダーを選択（Anthropic 直接または Anote サーバー経由）
4. API キーを入力
5. アクティビティバーからチャットパネルを開く
