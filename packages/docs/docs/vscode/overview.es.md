# Extensión de VS Code

La extensión de Anote para VS Code proporciona asistencia de IA en línea directamente en tu editor.

## Características

- **Barra lateral de chat** — panel de chat de IA persistente con historial de sesiones
- **Acciones de CodeLens** — Explicar / Arreglar / Pruebas / Refactorizar sobre cada función
- **Inyección de contexto** — añadir código o archivos seleccionados al chat
- **Búsqueda semántica** — buscar en tu código desde la paleta de comandos
- **Revisión de diferencias en línea** — aceptar o rechazar ediciones de IA archivo por archivo
- **Adjunto de archivos** — adjuntar imágenes, PDFs y archivos de texto al chat

## Instalación

Busca **"Anote"** en el mercado de extensiones de VS Code.

O a través de CLI:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Configuración Rápida

1. Abre VS Code
2. Ejecuta `Anote: Set Up` desde la paleta de comandos (`Ctrl+Shift+P`)
3. Elige tu proveedor (Anthropic directo o a través del servidor de Anote)
4. Ingresa tu clave API
5. Abre el panel de chat desde la barra de actividad
