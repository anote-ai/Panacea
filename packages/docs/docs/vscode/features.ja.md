# VS Code 拡張機能の特徴

## チャットサイドバー

アクティビティバーから Anote AI チャットパネルを開きます。コードベースに関する質問をし、コードの提案を受け取り、差分を確認します。

## インライン差分レビュー

エージェントがファイルの変更を提案すると、差分ビューが自動的に開きます。各変更を個別に受け入れるか拒否します。

## ストリーミングレスポンス

レスポンスはトークンごとにリアルタイムでストリーミングされます。ストップボタンを使って、ストリーミング中にキャンセルできます。

## ツール使用の可視性

エージェントが各レスポンス中に読み取り、書き込み、または実行するファイルを正確に確認できます。
