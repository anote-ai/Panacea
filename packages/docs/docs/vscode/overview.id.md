# Ekstensi VS Code

Ekstensi Anote VS Code menyediakan bantuan AI secara langsung di editor Anda.

## Fitur

- **Sidebar obrolan** — panel obrolan AI yang persisten dengan riwayat sesi
- **Tindakan CodeLens** — Jelaskan / Perbaiki / Uji / Refactor di atas setiap fungsi
- **Injeksi konteks** — tambahkan kode atau file yang dipilih ke obrolan
- **Pencarian semantik** — cari basis kode Anda dari palet perintah
- **Tinjauan perbedaan inline** — terima atau tolak edit AI file demi file
- **Lampiran file** — lampirkan gambar, PDF, dan file teks ke obrolan

## Instalasi

Cari **"Anote"** di pasar Ekstensi VS Code.

Atau melalui CLI:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Pengaturan Cepat

1. Buka VS Code
2. Jalankan `Anote: Set Up` dari palet perintah (`Ctrl+Shift+P`)
3. Pilih penyedia Anda (Anthropic langsung atau melalui server Anote)
4. Masukkan kunci API Anda
5. Buka panel obrolan dari Bilah Aktivitas
