# Возможности расширения VS Code

## Боковая панель чата

Откройте панель чата Anote AI из панели активности. Задавайте вопросы о вашем коде, получайте предложения по коду и просматривайте различия.

## Обзор различий в строках

Когда агент предлагает изменения в файлах, автоматически открывается представление различий. Принимайте или отклоняйте каждое изменение по отдельности.

## Потоковые ответы

Ответы поступают по токенам в реальном времени. Кнопка остановки позволяет вам отменить поток в любой момент.

## Видимость использования инструментов

Смотрите, какие файлы агент читает, записывает или выполняет во время каждого ответа.
