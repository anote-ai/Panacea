# Fitur Ekstensi VS Code

## Sidebar Obrolan

Buka panel obrolan Anote AI dari bilah aktivitas. Ajukan pertanyaan tentang kode Anda, dapatkan saran kode, dan tinjau perbedaan.

## Tinjauan Perbedaan Inline

Ketika agen mengusulkan perubahan file, tampilan perbedaan terbuka secara otomatis. Terima atau tolak setiap perubahan secara individu.

## Respons Streaming

Respons mengalir token demi token secara real-time. Tombol berhenti memungkinkan Anda membatalkan di tengah aliran.

## Visibilitas Penggunaan Alat

Lihat dengan tepat file mana yang dibaca, ditulis, atau dieksekusi oleh agen selama setiap respons.
