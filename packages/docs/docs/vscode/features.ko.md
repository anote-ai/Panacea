# VS Code 확장 기능

## 채팅 사이드바

활동 표시줄에서 Anote AI 채팅 패널을 엽니다. 코드베이스에 대한 질문을 하고, 코드 제안을 받으며, 차이를 검토합니다.

## 인라인 차이 검토

에이전트가 파일 변경을 제안할 때, 차이 보기(diff view)가 자동으로 열립니다. 각 변경 사항을 개별적으로 수락하거나 거부합니다.

## 스트리밍 응답

응답이 실시간으로 토큰 단위로 스트리밍됩니다. 중간에 취소할 수 있는 정지 버튼이 있습니다.

## 도구 사용 가시성

각 응답 중 에이전트가 읽고, 쓰고, 실행하는 파일을 정확히 확인할 수 있습니다.
