# Caratteristiche dell'estensione VS Code

## Barra laterale Chat

Apri il pannello chat di Anote AI dalla barra delle attività. Fai domande sul tuo codice, ricevi suggerimenti di codice e rivedi le differenze.

## Revisione delle differenze inline

Quando l'agente propone modifiche ai file, si apre automaticamente una vista delle differenze. Accetta o rifiuta ogni modifica singolarmente.

## Risposte in streaming

Le risposte vengono trasmesse token per token in tempo reale. Un pulsante di stop ti consente di annullare durante lo streaming.

## Visibilità dell'uso degli strumenti

Vedi esattamente quali file l'agente legge, scrive o esegue durante ogni risposta.
