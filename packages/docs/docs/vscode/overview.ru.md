# Расширение VS Code

Расширение Anote для VS Code предоставляет встроенную помощь ИИ прямо в вашем редакторе.

## Особенности

- **Боковая панель чата** — постоянная панель чата ИИ с историей сеансов
- **Действия CodeLens** — Объяснить / Исправить / Тесты / Рефакторинг над каждой функцией
- **Инъекция контекста** — добавьте выбранный код или файлы в чат
- **Семантический поиск** — ищите в вашем коде из палитры команд
- **Обзор различий в строках** — принимайте или отклоняйте правки ИИ файл за файлом
- **Прикрепление файлов** — прикрепляйте изображения, PDF и текстовые файлы к чату

## Установка

Ищите **"Anote"** в маркетплейсе расширений VS Code.

Или через CLI:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Быстрая настройка

1. Откройте VS Code
2. Запустите `Anote: Set Up` из палитры команд (`Ctrl+Shift+P`)
3. Выберите вашего провайдера (Anthropic напрямую или через сервер Anote)
4. Введите ваш API ключ
5. Откройте панель чата из панели активности
