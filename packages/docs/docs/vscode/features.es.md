# Características de la Extensión de VS Code

## Barra Lateral de Chat

Abre el panel de chat de Anote AI desde la barra de actividades. Haz preguntas sobre tu código, recibe sugerencias de código y revisa diferencias.

## Revisión de Diferencias en Línea

Cuando el agente propone cambios en los archivos, se abre automáticamente una vista de diferencias. Acepta o rechaza cada cambio de forma individual.

## Respuestas en Streaming

Las respuestas se transmiten token por token en tiempo real. Un botón de detener te permite cancelar a mitad de la transmisión.

## Visibilidad del Uso de Herramientas

Ve exactamente qué archivos lee, escribe o ejecuta el agente durante cada respuesta.
