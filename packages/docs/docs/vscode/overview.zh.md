# VS Code 扩展

Anote VS Code 扩展在您的编辑器中提供内联 AI 帮助。

## 功能

- **聊天侧边栏** — 持久的 AI 聊天面板，带有会话历史
- **CodeLens 操作** — 在每个函数上方解释 / 修复 / 测试 / 重构
- **上下文注入** — 将选定的代码或文件添加到聊天中
- **语义搜索** — 从命令面板搜索您的代码库
- **内联差异审查** — 按文件接受或拒绝 AI 编辑
- **文件附件** — 将图像、PDF 和文本文件附加到聊天中

## 安装

在 VS Code 扩展市场中搜索 **"Anote"**。

或者通过 CLI：

```bash
code --install-extension anote-ai.anote-ai-coding
```

## 快速设置

1. 打开 VS Code
2. 从命令面板运行 `Anote: Set Up` (`Ctrl+Shift+P`)
3. 选择您的提供者（直接使用 Anthropic 或通过 Anote 服务器）
4. 输入您的 API 密钥
5. 从活动栏打开聊天面板
