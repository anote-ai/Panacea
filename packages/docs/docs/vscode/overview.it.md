# Estensione VS Code

L'estensione Anote per VS Code fornisce assistenza AI inline direttamente nel tuo editor.

## Caratteristiche

- **Barra laterale chat** — pannello di chat AI persistente con cronologia delle sessioni
- **Azioni CodeLens** — Spiega / Correggi / Test / Rifattorizza sopra ogni funzione
- **Iniezione di contesto** — aggiungi codice o file selezionati alla chat
- **Ricerca semantica** — cerca nel tuo codice sorgente dalla palette dei comandi
- **Revisione delle differenze inline** — accetta o rifiuta le modifiche AI file per file
- **Allegato di file** — allega immagini, PDF e file di testo alla chat

## Installazione

Cerca **"Anote"** nel marketplace delle estensioni di VS Code.

Oppure tramite CLI:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Configurazione rapida

1. Apri VS Code
2. Esegui `Anote: Set Up` dalla palette dei comandi (`Ctrl+Shift+P`)
3. Scegli il tuo fornitore (Anthropic diretto o tramite server Anote)
4. Inserisci la tua chiave API
5. Apri il pannello di chat dalla barra delle attività
