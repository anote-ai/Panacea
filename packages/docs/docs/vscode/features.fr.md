# Fonctionnalités de l'extension VS Code

## Barre latérale de chat

Ouvrez le panneau de chat Anote AI depuis la barre d'activité. Posez des questions sur votre code, obtenez des suggestions de code et examinez les différences.

## Revue des différences en ligne

Lorsque l'agent propose des modifications de fichiers, une vue des différences s'ouvre automatiquement. Acceptez ou rejetez chaque changement individuellement.

## Réponses en streaming

Les réponses sont diffusées token par token en temps réel. Un bouton d'arrêt vous permet d'annuler en cours de diffusion.

## Visibilité de l'utilisation des outils

Voyez exactement quels fichiers l'agent lit, écrit ou exécute pendant chaque réponse.
