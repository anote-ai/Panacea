# VS Code Erweiterung

Die Anote VS Code Erweiterung bietet inline KI-Unterstützung direkt in Ihrem Editor.

## Funktionen

- **Chat-Seitenleiste** — persistentes KI-Chat-Panel mit Sitzungsverlauf
- **CodeLens-Aktionen** — Erklären / Beheben / Tests / Refaktorisieren über jeder Funktion
- **Kontextinjektion** — ausgewählten Code oder Dateien zum Chat hinzufügen
- **Semantische Suche** — durchsuchen Sie Ihren Codebestand über die Befehls-Palette
- **Inline-Diff-Überprüfung** — akzeptieren oder ablehnen Sie KI-Änderungen dateiweise
- **Dateianhang** — Bilder, PDFs und Textdateien an den Chat anhängen

## Installation

Suchen Sie nach **"Anote"** im VS Code Extensions-Marktplatz.

Oder über die CLI:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Schnelle Einrichtung

1. Öffnen Sie VS Code
2. Führen Sie `Anote: Einrichten` aus der Befehls-Palette (`Ctrl+Shift+P`) aus
3. Wählen Sie Ihren Anbieter (Anthropic direkt oder über den Anote-Server)
4. Geben Sie Ihren API-Schlüssel ein
5. Öffnen Sie das Chat-Panel aus der Aktivitätsleiste
