# VS Code 확장

Anote VS Code 확장은 편집기에서 직접 인라인 AI 지원을 제공합니다.

## 기능

- **채팅 사이드바** — 세션 기록이 있는 지속적인 AI 채팅 패널
- **CodeLens 작업** — 각 함수 위에 설명 / 수정 / 테스트 / 리팩토링
- **컨텍스트 주입** — 선택한 코드 또는 파일을 채팅에 추가
- **의미론적 검색** — 명령 팔레트에서 코드베이스 검색
- **인라인 차이 검토** — 파일별로 AI 편집을 수락하거나 거부
- **파일 첨부** — 이미지, PDF 및 텍스트 파일을 채팅에 첨부

## 설치

VS Code 확장 마켓플레이스에서 **"Anote"**를 검색하세요.

또는 CLI를 통해:

```bash
code --install-extension anote-ai.anote-ai-coding
```

## 빠른 설정

1. VS Code 열기
2. 명령 팔레트에서 `Anote: Set Up` 실행 (`Ctrl+Shift+P`)
3. 제공업체 선택 (Anthropic 직접 또는 Anote 서버를 통한)
4. API 키 입력
5. 활동 표시줄에서 채팅 패널 열기
