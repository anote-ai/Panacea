# Extension VS Code

L'extension Anote pour VS Code fournit une assistance IA en ligne directement dans votre éditeur.

## Fonctionnalités

- **Barre latérale de chat** — panneau de chat IA persistant avec historique de session
- **Actions CodeLens** — Expliquer / Corriger / Tests / Refactoriser au-dessus de chaque fonction
- **Injection de contexte** — ajouter du code ou des fichiers sélectionnés au chat
- **Recherche sémantique** — rechercher dans votre codebase depuis la palette de commandes
- **Révision des différences en ligne** — accepter ou rejeter les modifications de l'IA fichier par fichier
- **Pièce jointe de fichiers** — joindre des images, des PDF et des fichiers texte au chat

## Installation

Recherchez **"Anote"** dans le marché des extensions VS Code.

Ou via CLI :

```bash
code --install-extension anote-ai.anote-ai-coding
```

## Configuration rapide

1. Ouvrez VS Code
2. Exécutez `Anote: Set Up` depuis la palette de commandes (`Ctrl+Shift+P`)
3. Choisissez votre fournisseur (Anthropic direct ou via le serveur Anote)
4. Entrez votre clé API
5. Ouvrez le panneau de chat depuis la barre d'activité
