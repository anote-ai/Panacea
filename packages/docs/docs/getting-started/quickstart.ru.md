# Быстрый старт

## 1. Инициализация

```bash
anote init
```

Это проведет вас через настройку вашего API-ключа и предпочтительного поставщика LLM.

## 2. Задайте вопрос

```bash
# Общий вопрос
anote ask "как работает аутентификация в этом коде?"

# Сосредоточиться на файле
anote ask --file src/auth.ts "объясните это"

# Передать код
cat src/handler.py | anote ask "что может пойти не так здесь?"
```

## 3. Автоматическое исправление ошибок

```bash
# Исправить и повторять до тех пор, пока тесты не пройдут (до 5 раундов)
anote fix --loop --max-iterations 5
```

## 4. Индексация для семантического поиска

```bash
# Индексируйте вашу кодовую базу (запустите один раз, затем поддерживайте в актуальном состоянии)
anote index

# Семантический поиск
anote search "валидация JWT токена"
anote search "пул соединений с базой данных"
```

## 5. Просмотр PR

```bash
anote review --pr 42
```

## 6. Генерация журнала изменений

```bash
anote changelog --since v1.2.0
```
