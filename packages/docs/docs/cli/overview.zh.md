# CLI 概述

`anote` CLI 将 AI 助手直接带入您的终端。

## 安装

```bash
npm install -g @anote-ai/anote
```

## 核心命令

| 命令 | 描述 |
|---|---|
| `anote ask <question>` | 询问您的代码 |
| `anote fix [--loop]` | AI 辅助的错误修复 |
| `anote explain` | 解释文件或选择内容 |
| `anote review [--pr N]` | 代码审查或 PR 审查 |
| `anote test` | 生成或运行测试 |
| `anote refactor` | 重构代码 |
| `anote index` | 构建语义搜索索引 |
| `anote search <query>` | 语义代码搜索 |
| `anote commit` | 生成提交信息 |
| `anote changelog` | 生成变更日志 |
| `anote docs` | 生成文档 |
| `anote migrate` | AI 辅助的迁移 |
| `anote security` | 安全审计 |
| `anote perf` | 性能分析 |
| `anote doctor` | 检查环境健康 |
| `anote init` | 设置 Anote |
| `anote config` | 管理配置 |

请参见 [命令](commands.md) 以获取完整用法。
