# Ikhtisar CLI

CLI `anote` membawa bantuan AI langsung ke terminal Anda.

## Instalasi

```bash
npm install -g @anote-ai/anote
```

## Perintah Inti

| Perintah | Deskripsi |
|---|---|
| `anote ask <question>` | Tanyakan tentang kode Anda |
| `anote fix [--loop]` | Perbaikan bug dengan bantuan AI |
| `anote explain` | Jelaskan sebuah file atau pilihan |
| `anote review [--pr N]` | Tinjauan kode atau tinjauan PR |
| `anote test` | Hasilkan atau jalankan tes |
| `anote refactor` | Refactor kode |
| `anote index` | Bangun indeks pencarian semantik |
| `anote search <query>` | Pencarian kode semantik |
| `anote commit` | Hasilkan pesan commit |
| `anote changelog` | Hasilkan changelog |
| `anote docs` | Hasilkan dokumentasi |
| `anote migrate` | Migrasi dengan bantuan AI |
| `anote security` | Audit keamanan |
| `anote perf` | Analisis kinerja |
| `anote doctor` | Periksa kesehatan lingkungan |
| `anote init` | Siapkan Anote |
| `anote config` | Kelola konfigurasi |

Lihat [Perintah](commands.md) untuk penggunaan lengkap.
