# CLI Übersicht

Die `anote` CLI bringt KI-Unterstützung direkt in Ihr Terminal.

## Installation

```bash
npm install -g @anote-ai/anote
```

## Kernbefehle

| Befehl | Beschreibung |
|---|---|
| `anote ask <question>` | Fragen Sie zu Ihrem Code |
| `anote fix [--loop]` | KI-unterstützte Fehlerbehebung |
| `anote explain` | Erklären Sie eine Datei oder Auswahl |
| `anote review [--pr N]` | Code-Überprüfung oder PR-Überprüfung |
| `anote test` | Tests generieren oder ausführen |
| `anote refactor` | Code umstrukturieren |
| `anote index` | Semantischen Suchindex erstellen |
| `anote search <query>` | Semantische Codesuche |
| `anote commit` | Commit-Nachricht generieren |
| `anote changelog` | Änderungsprotokoll generieren |
| `anote docs` | Dokumentation generieren |
| `anote migrate` | KI-unterstützte Migrationen |
| `anote security` | Sicherheitsprüfung |
| `anote perf` | Leistungsanalyse |
| `anote doctor` | Überprüfen Sie die Umgebungsintegrität |
| `anote init` | Anote einrichten |
| `anote config` | Konfiguration verwalten |

Siehe [Befehle](commands.md) für die vollständige Nutzung.
