# Обзор CLI

CLI `anote` приносит AI-помощь прямо в ваш терминал.

## Установка

```bash
npm install -g @anote-ai/anote
```

## Основные команды

| Команда | Описание |
|---|---|
| `anote ask <question>` | Спросите о вашем коде |
| `anote fix [--loop]` | Исправление ошибок с помощью AI |
| `anote explain` | Объяснить файл или выборку |
| `anote review [--pr N]` | Код-ревью или ревью PR |
| `anote test` | Генерация или запуск тестов |
| `anote refactor` | Рефакторинг кода |
| `anote index` | Создание семантического поискового индекса |
| `anote search <query>` | Семантический поиск кода |
| `anote commit` | Генерация сообщения коммита |
| `anote changelog` | Генерация журнала изменений |
| `anote docs` | Генерация документации |
| `anote migrate` | Миграции с помощью AI |
| `anote security` | Аудит безопасности |
| `anote perf` | Анализ производительности |
| `anote doctor` | Проверка состояния окружения |
| `anote init` | Настройка Anote |
| `anote config` | Управление конфигурацией |

Смотрите [Команды](commands.md) для полного использования.
