# Panoramica del CLI

Il CLI `anote` porta assistenza AI direttamente nel tuo terminale.

## Installazione

```bash
npm install -g @anote-ai/anote
```

## Comandi Principali

| Comando | Descrizione |
|---|---|
| `anote ask <question>` | Chiedi riguardo al tuo codice |
| `anote fix [--loop]` | Correzione dei bug assistita da AI |
| `anote explain` | Spiega un file o una selezione |
| `anote review [--pr N]` | Revisione del codice o revisione PR |
| `anote test` | Genera o esegui test |
| `anote refactor` | Rifattorizza il codice |
| `anote index` | Costruisci l'indice di ricerca semantica |
| `anote search <query>` | Ricerca semantica del codice |
| `anote commit` | Genera messaggio di commit |
| `anote changelog` | Genera changelog |
| `anote docs` | Genera documentazione |
| `anote migrate` | Migrazioni assistite da AI |
| `anote security` | Audit di sicurezza |
| `anote perf` | Analisi delle prestazioni |
| `anote doctor` | Controlla la salute dell'ambiente |
| `anote init` | Configura Anote |
| `anote config` | Gestisci la configurazione |

Vedi [Comandi](commands.md) per un utilizzo completo.
