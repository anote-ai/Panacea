# Visão Geral do CLI

O `anote` CLI traz assistência de IA diretamente para o seu terminal.

## Instalação

```bash
npm install -g @anote-ai/anote
```

## Comandos Principais

| Comando | Descrição |
|---|---|
| `anote ask <question>` | Pergunte sobre seu código |
| `anote fix [--loop]` | Correção de bugs assistida por IA |
| `anote explain` | Explique um arquivo ou seleção |
| `anote review [--pr N]` | Revisão de código ou revisão de PR |
| `anote test` | Gere ou execute testes |
| `anote refactor` | Refatore o código |
| `anote index` | Construa o índice de busca semântica |
| `anote search <query>` | Busca semântica de código |
| `anote commit` | Gere mensagem de commit |
| `anote changelog` | Gere changelog |
| `anote docs` | Gere documentação |
| `anote migrate` | Migrações assistidas por IA |
| `anote security` | Auditoria de segurança |
| `anote perf` | Análise de desempenho |
| `anote doctor` | Verifique a saúde do ambiente |
| `anote init` | Configure o Anote |
| `anote config` | Gerencie a configuração |

Veja [Comandos](commands.md) para uso completo.
