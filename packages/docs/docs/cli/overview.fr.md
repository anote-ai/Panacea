# Vue d'ensemble de la CLI

La CLI `anote` apporte une assistance IA directement dans votre terminal.

## Installation

```bash
npm install -g @anote-ai/anote
```

## Commandes principales

| Commande | Description |
|---|---|
| `anote ask <question>` | Posez une question sur votre code |
| `anote fix [--loop]` | Correction de bugs assistée par IA |
| `anote explain` | Expliquer un fichier ou une sélection |
| `anote review [--pr N]` | Revue de code ou revue de PR |
| `anote test` | Générer ou exécuter des tests |
| `anote refactor` | Refactoriser le code |
| `anote index` | Construire un index de recherche sémantique |
| `anote search <query>` | Recherche de code sémantique |
| `anote commit` | Générer un message de commit |
| `anote changelog` | Générer un journal des modifications |
| `anote docs` | Générer de la documentation |
| `anote migrate` | Migrations assistées par IA |
| `anote security` | Audit de sécurité |
| `anote perf` | Analyse de performance |
| `anote doctor` | Vérifier la santé de l'environnement |
| `anote init` | Configurer Anote |
| `anote config` | Gérer la configuration |

Voir [Commandes](commands.md) pour une utilisation complète.
