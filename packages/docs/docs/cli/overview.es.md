# Resumen del CLI

El CLI de `anote` trae asistencia de IA directamente a tu terminal.

## Instalación

```bash
npm install -g @anote-ai/anote
```

## Comandos Principales

| Comando | Descripción |
|---|---|
| `anote ask <question>` | Pregunta sobre tu código |
| `anote fix [--loop]` | Corrección de errores asistida por IA |
| `anote explain` | Explicar un archivo o selección |
| `anote review [--pr N]` | Revisión de código o revisión de PR |
| `anote test` | Generar o ejecutar pruebas |
| `anote refactor` | Refactorizar código |
| `anote index` | Construir índice de búsqueda semántica |
| `anote search <query>` | Búsqueda de código semántica |
| `anote commit` | Generar mensaje de commit |
| `anote changelog` | Generar registro de cambios |
| `anote docs` | Generar documentación |
| `anote migrate` | Migraciones asistidas por IA |
| `anote security` | Auditoría de seguridad |
| `anote perf` | Análisis de rendimiento |
| `anote doctor` | Verificar la salud del entorno |
| `anote init` | Configurar Anote |
| `anote config` | Gestionar configuración |

Consulta [Comandos](commands.md) para el uso completo.
