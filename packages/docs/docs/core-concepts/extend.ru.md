# Расширение Panacea

Два способа настроить поведение Panacea в вашем проекте: **CLAW.md** для постоянных инструкций и **hooks** для выполнения ваших собственных команд вокруг вызовов инструментов.

## CLAW.md — память проекта

`CLAW.md` — это файл markdown, который Panacea читает для контекста проекта — та же идея, что и README, но ориентированная на агента, а не на человека. `anote init` автоматически генерирует его, предварительно заполнив обнаруженным стеком и командами проверки (тест/линт/сборка):

```markdown
# CLAW.md

Этот файл предоставляет рекомендации Anote AI при работе с кодом в этом репозитории.

## Обзор проекта

<!-- Опишите, что делает этот проект -->

## Стек

TypeScript · Next.js

## Проверка

Запустите это перед тем, как считать изменение завершенным:

  npm test
  npm run lint

## Рабочее соглашение

- Читайте соответствующие файлы перед внесением изменений
- Запускайте команды проверки после изменения логики
- Держите изменения небольшими и сосредоточенными
- Предпочитайте редактирование существующих файлов вместо создания новых
```

Редактируйте его свободно — добавляйте заметки по архитектуре, соглашения или вещи, которые агент продолжает делать неправильно. Panacea читает его в начале каждой сессии в этой директории.

## Hooks — выполняйте свои собственные команды вокруг вызовов инструментов

Hooks выполняют команду оболочки перед (`preToolUse`) или после (`postToolUse`) каждого вызова инструмента, настраиваемого в `.anote.json`:

```json
{
  "hooks": {
    "preToolUse": ["./scripts/check-tool-policy.sh"],
    "postToolUse": ["npx prettier --write ."]
  }
}
```

**Семантика кодов выхода:**

| Код выхода | Эффект |
|---|---|
| `0` | Разрешить — stdout захватывается как информационное сообщение |
| `2` | Запретить — stdout захватывается как причина, показываемая агенту |
| любой другой | Предупредить, но разрешить |

Используйте `preToolUse`, чтобы заблокировать рискованные команды или обеспечить соблюдение политики перед их выполнением; используйте `postToolUse` для таких вещей, как автоформатирование после каждого редактирования.
