# Panaceaの仕組み

Panaceaは**エージェントループ**を実行します：プロンプトを読み取り、どのツールを呼び出すか決定し、実行し、結果を読み取り、これを繰り返します — 推論と編集をストリーミングで返しながら — タスクが完了するか、ターン制限に達するまで続けます。

## ツール

デフォルトでは、Panaceaのエージェントは以下を呼び出せます：

| ツール | 目的 |
|---|---|
| `Read` | ファイルを読み取る |
| `Write` | ファイルを作成または上書きする |
| `Edit` | ファイルに対象を絞った変更を加える |
| `Bash` | シェルコマンドを実行する |
| `Glob` | パターンでファイルを検索する |
| `Grep` | ファイル内容を検索する |

一部のコマンドはこのリストを制限します — 例えば `anote review` と `anote diff` は `Read`、`Glob`、`Grep`、`Bash` のみを許可します。レビューはファイルを書き込むべきではないためです。

## ターンとコンパクション

各ツール呼び出し/応答のペアが1ターンとしてカウントされます。エージェントは `maxTurns`（デフォルト30、`anote config set maxTurns <n>` または `.anote.json` で設定可能）の後に停止します。長いセッションは、コンテキストウィンドウを管理しやすく保つため、`compactAfterMessages`（デフォルト40）の後にコンパクション（圧縮）されます。

## ストリーミング

すべてのサーフェス — CLI、VS Code、Web、デスクトップ — は同じバックエンドエンドポイント（`POST /api/chat/stream`）と通信し、モデルの応答とツールの活動をSSEでリアルタイムにストリーミングします。ファイルの読み取り、編集、コマンドの出力をライブで確認でき、最終的な回答だけではありません。

## マルチプロバイダー

エージェントループは1つのモデルに縛られません。`anote ask --compare` は同じプロンプトを複数のモデルで並べて実行し、ほとんどのコマンドの `--model` は設定済みの任意のプロバイダー（`claude-sonnet-4-6`、`gpt-4.1`、`gemini-2.5-pro`、またはローカルの `ollama/<model>`）を受け付けます。
